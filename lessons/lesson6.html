流程控制：if, else if 與 else

條件判斷讓程式具備「思考與決策」的能力。根據運算式的真偽（bool：true / false），執行不同的程式碼區塊。

1. 關係運算子與常見陷阱

== (等於) | != (不等於)
> | < | >= | <=
⚠️ 大坑警告：
if (score = 60) 是把 60 賦值給 score，條件永遠成立！判斷相等請一定要寫兩個等於：if (score == 60)。

2. 複合條件與短路求值 (Short-Circuit)

  • && (AND)：兩邊皆為 true 才為 true
  • || (OR)：任一邊為 true 即為 true
  • ! (NOT)：反轉邏輯 (true 變 false)

💡 短路求值：對於 A && B，若 A 為 false，C++ 將**完全不會計算 B**；對於 A || B，若 A 為 true，也將直接跳過 B。

3. 條件判斷鏈的互斥性

if ... else if ... else 具備上到下的**互斥執行**特性。一旦其中一個條件成立，後續的區塊將自動被跳過。
