迴圈：讓程式重複做事

if 是判斷「一次」，迴圈則是「只要條件成立，就一直重複」。右側有 3 個觀摩範例與 3 個漸進實作題目。

三種迴圈語法：

  • while：while (條件) { ... }　先判斷再執行，適合「不知道要跑幾次」。
  • for：for (初始; 條件; 更新) { ... }　適合「已知次數」。
  • do-while：do { ... } while (條件);　先執行一次再判斷，結尾有分號。
  • break / continue：break 跳出整個迴圈；continue 跳過本輪、進入下一輪。

常見坑點：

  • 無窮迴圈：忘了更新變數（如漏寫 i++），條件永遠成立，程式停不下來。
  • 多餘分號：for (...); 後面的分號會讓迴圈本體變成空的。
  • 差一錯誤：i < 5 跑 5 次 (0~4)，i <= 5 跑 6 次，邊界要想清楚。
