cin 標準輸入流與輸入機制

cin（Character Input）用來從標準輸入讀取資料。理解 cin 的流向與緩衝區機制，是寫出穩定程式的關鍵。

1. 提取運算子 (>>) 與空白字元跳過機制

cin >> var; 會從輸入緩衝區中讀取資料並塞入變數中。

自動忽略前導空白：>> 會自動跳過開頭的**空白、Tab、換行符 (\n)**。

定界符（Delimiter）：讀取文字或數字時，遇到下一個空白或換行就會**停止讀取**。

// 若 Stdin 輸入: "Alex 25"
cin >> name; // name 得到 "Alex"
cin >> age; // age 得到 25

2. 鏈式輸入 (Cascading cin)

可以將多個輸入合併在一行寫法：

cin >> length >> width >> height;

這會依序尋找輸入緩衝區中的前三個資料項，彼此間用空白或換行隔開即可。

嚴謹思考：型態不匹配與 failbit

如果宣告 int age;，使用者卻輸入了 "abc"，cin 會進入**錯誤狀態 (Fail State)**，讀取失敗，且 age 會被預設給予 0！後續的 cin 也將全部失效。
