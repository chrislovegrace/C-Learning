創作者名片產生器

本課為第一階段總結專案！你將整合 string, int, double, cin 與 cout，打造一個自動計算與排版名片的程式。

專案規格說明

程式需依序透過 Stdin 讀取 4 個關鍵欄位：

  1. string creatorName - 創作者名稱
  2. int subscriberCount - 訂閱人數
  3. double avgViews - 影片平均觀看數
  4. int videoCount - 總上片數量

內部需自動計算出衍生指標：
頻道總總觀看數 = avgViews * videoCount

ASCII 排版技巧

善用字元符號（如 =、|、*）與換行 endl，可以在 Console 機印出結構完美的卡片框線。
