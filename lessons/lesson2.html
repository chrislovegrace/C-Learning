變數宣告與基礎資料型態

在程式中，「變數」就像是貼有標籤的**記憶體盒子**，用來暫存資料。宣告變數時，必須明確告知 C++ 這個盒子要裝什麼類型的資料。

變數宣告與初值設定

int age; // 1. 宣告：準備一個放整數的盒子
age = 18; // 2. 賦值：放入數值 18
int score = 95; // 也可以宣告同時給初值！

四大常用基礎資料型態

int 整數 (Integer)

儲存沒有小數點的整數，例如：10, -5, 0

4 Bytes
double 雙精度浮點數 (Decimal)

儲存包含小數點的實數，例如：3.14159, -0.5

8 Bytes
char 單一字元 (Character)

只儲存**單個字元**，須用單引號包裹：'A', '!'

1 Byte
string 字串 (Text)

儲存一段文字，須使用雙引號："Hello World"
（需包含 <string> 標頭檔）

標頭檔
bool 布林值 (Boolean)

表示邏輯判斷，只有兩種值：true (真) 或 false (假)

1 Byte
初學者極易犯錯的細節：
  • 引號差異：'A' (char 用單引號) 與 "A" (string 用雙引號) 完全不同！
  • 整數除法：兩個 int 相除（例如 5 / 2）結果會自動截斷小數變成 2！要保留小數必須至少有一個數為 double。
  • 變數命名：不能以數字開頭，且不能使用 C++ 關鍵字（如 int, return）。
