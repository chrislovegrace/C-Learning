算術運算與變數修改

程式不只儲存資料，更能對資料進行運算。本單元將深入解析 C++ 的基本四則運算、取餘數、複合賦值以及遞增/遞減運算子。

1. 基礎算術與「型態強制轉換」

在 C++ 中，運算符號包含 + - * / %。其中最容易踩坑的是除法 (/)：

int a = 7, b = 2;
cout << a / b; // 印出 3 （小數點被強制無條件捨去！）
cout << (double)a / b; // 印出 3.5 （轉型後保留精度）
💡 規則：只要參與運算的兩邊都是 int，結果一定是 int；只要有一邊是 double，結果就會提升為 double。

2. 取餘數運算子 (%) 的神奇用途

% 取得的是除法後的「餘數」（例：7 % 3 == 1）。
常見應用情境：

  • 判斷奇偶數：num % 2 結果為 0 代表偶數，1 代表奇數。
  • 時間單位換算：例如把秒數換算成「幾分幾秒」。
  • 限制範圍：任何數 % N 的結果一定介於 0 ~ N-1 之間。

3. 變數修改與遞增 (++) 順序

// 1. 複合賦值（寫法簡化）
score += 10; // 等同於 score = score + 10
// 2. 前綴 vs 後綴 ++ 的差異
int x = 5;
int y = x++; // 先把 x(5) 給 y，x 再變 6 ➔ y=5, x=6
int z = ++x; // x 先加 1(變 7)，再給 z ➔ z=7, x=7
